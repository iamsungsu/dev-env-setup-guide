# Collaboration & Development Guide

Git과 GitHub를 활용한 협업 방법, 실제 프로젝트를 진행 시 필요한 관련 지식 등을 정리했습니다.

## 문서 기술 목적

- **협업 과정 이해:** 프로젝트를 진행할 때 필요한 Git 브랜치 관리, 코드 공유, 병합 등의 협업 과정을 이해
- **지식 공유 및 활용:** 프로젝트 팀원과 협업 방법을 공유 및 실제 팀 프로젝트에 적용
- **학습 내용 기록 및 관리:** 개발 과정에서 학습한 개념과 실습 내용을 문서로 정리하여 필요할 때 다시 참고할 수 있도록 보관
